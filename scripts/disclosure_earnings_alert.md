# 잠정실적 텔레그램 알림

포착 공시 제목에 "(잠정)실적"이 있으면 기존 실시간 알림 경로에서 정보를 보강합니다.
별도 예약 배치를 추가하지 않습니다. "(잠정) 실적"처럼 공백이 있어도 처리합니다.
기존 공시예고 → 일정 등록 배치, 키워드 목록과 최초 스캔 알림 생략 정책은 유지합니다.

## 데이터 출처

- 기업명·보고서명·실적기간·현재 실적: DART 본문.
- 종목코드: 현재 공시에서 연결한 DART 기업정보를 우선 확인합니다.
  실패 시 base_info/company_stock_map.json의 companies 목록과
  base_info/company_stock_aliases.json의 명시적 별칭을 차례로 확인합니다.
- 과거 실적·시장 예상치: WiseReport Financial Summary의 분기 표.
- 시가총액·기준일: WiseReport 기업현황의 시세정보.

시가총액과 예상치는 조회 시점 데이터이며 공시 발표 순간의 값으로 보장하지 않습니다.
메시지에는 WiseReport K-IFRS의 연결/별도 기준과 시가총액 기준일을 표시합니다.
AWAKEPLUS는 사용하지 않습니다.
현재 순이익은 지배주주순이익이 아닌 전체 당기순이익입니다.
WiseReport에서도 "당기순이익" 행을 사용하며 "(지배)" 행은 제외합니다.

첫 줄은 기존 감성 이모지와 📢 뒤에 "기업명 - 보고서명"을 붙입니다.
둘째 줄은 시가총액과 A종목코드이며, 추이 제목에 연결/별도 기준을 표시합니다.
마지막에는 공시링크와 해당 종목의 WiseReport 과거실적 링크를 각각 별도 줄로 표시합니다.

## 추출 규칙

1. DART 접수번호로 공시 페이지를 읽고 viewDoc의 문서번호와 본문 인자를 찾아 본문을 조회합니다.
2. 분기 실적기간과 금액 단위를 확인합니다. 누계가 아닌 "당해실적"의 "당기실적"을 읽습니다.
3. 공시 페이지의 openCorpInfoNew 기업 고유번호로 DART 기업정보를 조회합니다.
   공시회사명이 현재 공시와 일치하고 종목코드가 유일한 경우 해당 코드를 사용합니다.
   조회 실패 시 기존 기업명 매칭 파일, 명시적 별칭 순으로 확인합니다.
   부분일치나 유사도 기반으로 종목코드를 추측하지 않습니다.
4. WiseReport 기업현황 페이지에서 분기 표 요청에 필요한 동적 매개변수를 새로 읽습니다.
5. 영업(잠정)실적(공정공시)은 K-IFRS 별도(fin_typ=3),
   연결재무제표기준영업(잠정)실적(공정공시)은 K-IFRS 연결(fin_typ=4)로 조회합니다.
   분기는 freq_typ=Q이며 응답 표의 회계기준도 공시와 같은지 확인합니다.
   다른 기준의 표가 반환되면 사용하지 않습니다. 해당 기준의 예상치·과거 실적이
   없으면 -로 표시하며, 주재무제표나 다른 회계기준으로 대체하지 않습니다.
6. 대상 분기보다 앞선 정확한 4개 분기를 고릅니다. (E) 열은 과거 실적으로 쓰지 않습니다.
   대상 분기의 (E) 열만 예상치로 사용합니다.
7. 영업이익 행이 비어 있을 때는 "영업이익(발표기준)" 행을 확인합니다.
8. 셀의 title 속성에 소수점 금액이 있으면 해당 값을 사용합니다.
   금액을 억원으로 통일하고 비율 계산 후 표시용 정수만 반올림합니다.

예상 대비는 (실제 - 예상) / |예상| × 100입니다.
예상치가 음수여도 손실 축소는 +, 손실 확대는 -로 표시합니다.
예상치가 없거나 0이면 비율을 표시하지 않습니다.
누락된 실적이나 예상치는 "-"로 표시하고 0으로 채우지 않습니다.
일반적인 달력 분기 외 기간 또는 지원하지 않는 단위는 기존 제목·링크 알림으로 대체합니다.

## 실패 처리와 운영

- DART 요청/본문 파싱 실패: 기존 제목·링크 알림.
- 매칭 파일 부재/매칭 실패/WiseReport 오류: 확인한 DART 현재 실적만 제공.
- 일반 뉴스·해외 뉴스·다른 유형 공시: 기존 알림.
- 추가 HTTP 요청은 각 요청에 8초 제한이 있고, 수집 데이터 잠금 밖에서 실행합니다.
- 기존 RSS 수집 스레드에서 동기로 보강하므로 외부 사이트 지연 시 해당 수집 스레드의
  알림 및 다음 수집 처리가 지연될 수 있습니다.
- 서버에 코드 반영 후 앱을 재시작해야 적용됩니다.
- 매칭 파일이 없으면 프로젝트 루트에서 python3 company_list_sync_scheduler.py를 실행합니다.

## 공시회사명과 거래소 종목명 차이

롯데칠성음료 공시의 DART 기업정보는 종목코드 005300을 제공합니다.
거래소 종목명이 롯데칠성으로 저장되어 있어도 DART 종목코드로 처리할 수 있습니다.
DART 기업정보를 조회할 수 없는 상황을 위해 company_stock_aliases.json에도
"롯데칠성음료": "005300"을 등록해 두었습니다.
추가 별칭은 공시회사명을 키로, 6자리 종목코드 문자열을 값으로 관리합니다.
기존 company_stock_map.json과 키워드 관리 센터의 company_kr 목록은 변경하지 않습니다.
이미 전송된 알림이나 저장된 과거 실적 기록을 자동 재처리하거나 재전송하지는 않습니다.

검증: python -m unittest discover -s tests
테스트는 Telegram 전송과 외부 요청을 모의하며 실제 알림을 발송하지 않습니다.
fixtures/earnings는 2026-11-03 하나투어 공시와 WiseReport에서 확인한 표를 사용합니다.
